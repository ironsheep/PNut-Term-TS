# Handoffs FROM the skills side

Inbound counterpart to `handoffs-to-SKILLS-AGENT/`.

That folder holds work this project sends *out* — skill updates authored here for
the central skill set. This folder holds work arriving *in*: briefs, pilots, and
process changes issued from the skills side for this project to act on.

Naming follows the same convention — subject plus issue date, e.g.
`CHANGELOG-VOICING-PILOT-2026-07-27.md`.

Each document states its own lifetime. Pilot briefs are temporary and are deleted
at sign-off along with whatever they installed.
