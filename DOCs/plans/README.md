# DOCs/plans/

Canonical home for **sprint-plan documents** produced by the central skill
set (`sprint-plan`, `plan-to-tasks`, etc.). This directory is named in
`.claude/skill-conventions.md` as `PLAN_DIR`.

- **Active plans** live here as flat files (default pattern
  `<NAME>-SPRINT-PLAN.md`).
- **`archive/`** holds completed-sprint artifacts: closeouts
  (`<YYYY-MM-DD>-<NAME>-Sprint-Closeout.md`), retrospectives, and
  punch-list snapshots.

## Legacy plan locations (not swept automatically)

Two older plan locations predate this convention and remain in place for
history. New plans should land here, not in these:

- **`sprint-plans/`** (repo root) — window-upgrade plans and a `comparison/`
  subdir.
- **`DOCs/project-sprints/`** — dated per-sprint folders
  (`<Name>-Sprint-<YYYYMMDD>/`) with their own artifacts.
